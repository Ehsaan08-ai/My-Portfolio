# Design Analysis - Redoyan's Portfolio Reference

## Key Observations from Reference Site

### Layout & Structure
- **Hero Section**: Large animated text with loading bar effect
- **Navigation**: Sticky top nav with logo and menu items (About, Work, Contact, Resume)
- **Content Flow**: Vertical scrolling with smooth transitions
- **Section Dividers**: Clean separations between sections

### Animations & Interactions
- **Text Reveals**: Staggered text animations on scroll (Framer Motion)
- **Loading Bar**: Animated progress bar in hero section
- **Hover Effects**: Smooth transitions on interactive elements
- **Scroll Triggers**: Elements animate as they enter viewport

### Color & Typography
- **Background**: Light/neutral background with dark text
- **Accent Colors**: Subtle color accents for CTAs
- **Typography**: Clear hierarchy with bold headers and readable body text
- **Icons**: Simple, clean icon style with consistent stroke weight

### Components
- **Cards**: Minimal design with subtle shadows and borders
- **Buttons**: Clean CTAs with hover states
- **Tech Stack Icons**: Grid layout with icon + label pairs
- **Timeline**: Vertical timeline with dates and descriptions

## Design Philosophy for Ehsaan's Portfolio
- **Luxury Theme**: Deep obsidian black (#050505) background
- **Gold Accents**: Metallic Gold (#D4AF37) for primary elements
- **Champagne Gold**: #FFD700 for secondary accents and hover states
- **Card Design**: Shadcn-style cards with dark bronze borders and backdrop blur
- **3D Integration**: Spline robot as centerpiece in hero
- **Animations**: Framer Motion for text reveals, GSAP ScrollTrigger for robot interactions
